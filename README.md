# EduSaathi

Your calm study companion. EduSaathi puts planning, learning, attendance, doubts, community and career prep in one Android app, built to stay easy on the eyes and work with unstable internet.

## Features

- **Today:** To-do list with deadlines, Pomodoro focus timer with a sound when it ends, streaks and a daily plan generated by AI.
- **Lectures:** Add your own YouTube lectures, name and edit them, and resume where you left off, with progress shown for each.
- **Study tools:** Notebook with summaries, quizzes and flashcards, an AI tutor, a notes summariser and a video summariser.
- **Plan:** Exam roadmap, attendance tracker that shows how many classes you can miss, mock tests, and a custom agenda for mind, body and study habits.
- **Connect:** Class groups, co-working room, mood check-in and mock interviews.
- **Resume builder:** Three templates, AI help for summaries, bullets, skills and cover letters, job-description matching and an ATS score.
- **Personalise:** Themes, accent colours, fonts, wallpapers, glass-style UI and motion settings.

## AI

EduSaathi uses open-source models (Llama and others). Choose your engine in **Me → AI engine**:

- **Groq** (free key, fastest)
- **OpenRouter** (free key)
- **Community server** (no key, slower)
- **On-device** (WebLLM, needs WebGPU)
- **Your own OpenAI-compatible server**

Your API key stays on your device.

## Tech

Single-file HTML, CSS and JavaScript app packaged for Android with [Capacitor](https://capacitorjs.com). Progress saves locally on the device.
